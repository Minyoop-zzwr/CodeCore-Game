# 🧩 CodeCore-Game

一个基于 Pygame 的迷宫探索游戏，通过本地部署的 DeepSeek-R1 模型驱动实时叙事对话。

---

## 🎮 当前功能

### 已实现
- 键盘方向键控制角色在迷宫中移动
- 墙壁碰撞检测
- 按空格键触发 AI 生成场景描述与鼓励
- 完全本地运行，无需联网，无需 API Key（基于 Ollama + DeepSeek-R1 1.5B）
- 开场动画：CHAPTER 1: DESCEND 章节标题淡入淡出
- 迷雾效果：仅可见玩家周围约 5×5 格子，越近越清晰
- 复杂迷宫：16×10 扩展至 32×20，包含岔路与死路
- 入口与出口标记：左上角为入口，右下角为金色出口
- RPG 风格对话框：AI 回复以聊天气泡形式显示在地图下方
- 第一章 ORIGIN：二进制地图（0和1）+ 绿色终端对话框 + 预设二进制消息
- 第二章 SYNTAX：ASCII 字符墙壁 + 青色终端对话框 + print 格式回复

---

## 🛠️ 技术栈

- 游戏引擎：Pygame 2.6.1
- AI 推理：Ollama + DeepSeek-R1 1.5B (GGUF)
- 语言：Python 3.13
- 通信：本地 HTTP API
- 版本管理：Git + GitHub（分支开发 + PR 合并）

## 🚀 如何运行

**前提条件**：安装 Python 3.13+ 和 Ollama（https://ollama.com）

**步骤1：克隆仓库**
git clone https://github.com/Minyoop-zzwr/CodeCore-Game.git
cd CodeCore-Game

**步骤2：安装 Python 依赖**
pip install pygame requests

**步骤3：下载并运行 AI 模型（首次运行，约1.1GB，只需一次）**
ollama run deepseek-r1:1.5b

**步骤4：启动游戏**
python main.py

**游戏操作**：方向键移动，空格键触发 AI 对话

## 📌 设计理念

游戏采用“章节视觉进化”的设计，用不同章节的地图风格隐喻 AI 的成长过程：

| 章节 | 视觉风格 | 隐喻 |
|------|----------|------|
| 第一章 | 纯 0 和 1 组成的黑白迷宫 | 机器语言，二进制起源 |
| 第二章 | ASCII 字符地图，绿色终端风格 | 人类可读的代码 |
| 第三章 | 彩色渐变 + 迷雾效果 | 感知觉醒，探索未知 |
| 第四章 | 机械臂实验室（软硬结合） | 软件控制硬件，关节空间控制 |
| 第五章 | 不规则图形地图 | 突破范式，进入更高维度 |
