# 🧩 CodeCore - 代码之核

一个基于 Pygame 的 2D 迷宫探索游戏，通过本地部署的 DeepSeek-R1 模型驱动实时叙事对话。用章节视觉进化隐喻 AI 的成长过程。

---

## 📖 项目简介

《CodeCore》是一款以"AI 觉醒"为主题的迷宫探索游戏。玩家扮演一个在数字世界中刚刚苏醒的智能核心，通过探索不同风格的章节，逐步从二进制底层进化到具备感知、认知与物理控制能力的智能体。

游戏最大的特色是用视觉风格的演进隐喻 AI 的进化过程，并在一系列关卡中融入机器人工程的核心概念。

## ✅ 已实现功能

### 核心系统
- 启动菜单：继续游戏 / 新游戏 / 玩法说明
- 存档系统：自动保存章节与位置到 save.json，支持从上次进度继续
- 章节切换：到达出口按 Enter 触发过渡动画，自动进入下一章
- 暂停菜单：游戏中按 ESC 弹出确认框，支持鼠标操作

### 视觉
- 第一章：绿色密集字符 + 代码雨背景
- 第二章：密集符号墙 + 金色闪烁数据碎片
- 第三章：彩色渐变墙壁 + 迷雾效果 + 已探索区域记忆
- 玩家发光光晕 + 连续渐变拖尾（静止后淡出）
- 对话框打字机效果 + 末尾光标闪烁
- 章节标题变大变粗 + 故障抖动 + 红色重影
- 扫描线 CRT 复古滤镜

### 玩法
- 方向键移动，长按可持续移动（各章节速度可配置）
- 第二章：数据碎片收集系统（5 个碎片，收集后触发特殊文本）
- 第三章：迷雾逐渐消散，走过的区域保持可见
- 第四章：三关节机械臂控制，三方块搬运任务
  - Q/E 控制肩关节，A/D 控制肘关节，Z/C 控制腕关节
  - F 键抓取/释放方块
  - 走到控制台按 Enter 激活机械臂
  - 三方块（金/蓝/粉）与对应颜色目标位置匹配
  - 全部放置完成 → 暗格门打开

### AI 对话
- 本地部署 Ollama + DeepSeek-R1 1.5B，完全免费、离线可用
- 第一章：显示预设的二进制消息（ASCII 编码的"你好""人类"等）
- 第二章：print("...") 格式的代码风格回复
- 第三章：DeepSeek 实时生成的氛围描述与鼓励
- 第四章：> system: 橙色机械工程风格提示

## 💡 技术亮点

| 技术点 | 实现说明 |
|--------|----------|
| 本地 AI 部署 | 使用 Ollama 在本地运行 DeepSeek-R1，通过 HTTP API 调用，无需联网 |
| 状态机 | 游戏状态（menu/help/intro/playing）与章节过渡状态（fading_out/title/fading_in）分离管理 |
| 逆运动学 | 三关节机械臂用三角函数计算末端位置，支持关节角度控制 |
| 距离场算法 | 迷雾效果按玩家到各格子的距离计算遮罩透明度，实现平滑渐变 |
| JSON 持久化 | 存档系统将章节与坐标序列化为 JSON 文件 |
| 动态渲染 | 每章使用不同的渲染模式（binary/ascii/gradient/robot），同一份地图数据驱动不同视觉效果 |

## 🚀 如何运行

### 前提条件
- Python 3.13+
- Ollama（https://ollama.com），用于本地 AI 推理

### 步骤

第一步，克隆仓库
git clone https://github.com/Minyoop-zzwr/CodeCore-Game.git
cd CodeCore-Game

第二步，安装 Python 依赖
pip install pygame requests

第三步，下载并运行 AI 模型（首次运行约 1.1GB）
ollama run deepseek-r1:1.5b

第四步，启动游戏
python main.py

### 操作说明
- 方向键：移动（长按持续移动）
- 空格键：呼叫 AI
- Enter：章节切换 / 激活控制台
- ESC：暂停退出
- F：第四章抓取/释放方块
- Q/E/A/D/Z/C：第四章控制机械臂关节
